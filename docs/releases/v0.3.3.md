# Notas de la Versión - v0.3.3

**Fecha:** Marzo 2026
**Enfoque:** desacoplar el fallback individual a CvLAC del flujo base de sincronización para no degradar el tiempo de carga principal.

## 🚀 Cambios en Backend

### Sincronización base más liviana
* `sync_scienti` ya no dispara consultas individuales a `CvLAC` durante el paso estándar de enriquecimiento de investigadores.
* El comando `enrich_researchers` sigue consultando `datos.gov.co` como fuente principal dentro del flujo base.

### Fallback lento aislado
* `enrich_researchers` ahora soporta `--with-cvlac` para ejecutar el fallback histórico de forma explícita.
* También soporta `--cvlac-only` para correr únicamente la parte lenta sobre investigadores que aún no tienen categoría.
* Se añadió el script `scripts/run_cvlac_enrichment_background.sh` para lanzar ese fallback en segundo plano desde un entorno con Docker.

## 🛡️ Consideraciones

* La aplicación queda operativa con el enriquecimiento base; el paso lento pasa a ser opcional y no bloqueante.
* El script de background escribe logs locales para seguimiento sin interferir con la sincronización principal.
