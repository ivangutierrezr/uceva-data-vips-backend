# Release v0.1.0 — UCEVA Data VIPS Backend

## Resumen
La versión **0.1.0** establece una base funcional y mantenible del backend Django para consulta y exportación de datos académicos.

## Alcance
- API backend Django operativa para consumo de frontend.
- Reorganización de utilidades de exportación a estructura interna reutilizable.
- Limpieza inicial de scripts legacy/debug y comentarios explicativos no necesarios.
- Estandarización del repositorio (incluyendo `.gitignore` backend).

## Cambios principales

### 1) Reorganización de exportaciones
- Centralización de la lógica de exportación en `scienti/utils/exports/`.
- Desacople de lógica de negocio en scripts de raíz.
- Conservación de wrappers para compatibilidad operativa.

### 2) Limpieza de scripts y redundancias
- Reubicación de scripts de depuración a carpeta de scripts utilitarios.
- Eliminación de archivos redundantes/obsoletos detectados en auditoría.
- Reducción de ruido en raíz del proyecto.

### 3) Limpieza de código
- Eliminación de comentarios extensos no funcionales.
- Conservación de comentarios técnicos necesarios.
- Mejora de legibilidad general.

### 4) Salud del repositorio
- `.gitignore` backend organizado por secciones (Python/Django, env, tests, build, tooling, IDE/OS).

## Validación
- `python manage.py check` ✅

## Riesgos / pendientes
- Persisten scripts históricos que requieren segunda ronda de depuración funcional.
- Recomendable ampliar cobertura de pruebas automatizadas para comandos de exportación.

## Breaking changes
- No se esperan breaking changes de API pública.
- Cambios de organización interna de scripts/utilidades (impacto bajo para consumidores externos).

## Próximos pasos (v0.1.x)
- Añadir pruebas para utilidades de exportación y management commands.
- Completar barrido de comentarios/código muerto en módulos restantes.
- Documentar flujo estándar de exportes por entorno.
