# Notas de la Versión - v0.2.0

**Fecha:** Marzo 2026
**Enfoque:** Endpoints de Profundización (Drill-Down), Exportación en Excel Robusta, Búsqueda Global y Post-Procesamiento de Scraping.

## 🚀 Nuevas Características y Endpoints (API)

* **Endpoints de Profundidad (Detail Views):** Creación del ecosistema de vistas completas en el core (`views.py` / `urls.py`) para consumir objetos unitarios en el Front-end:
  * Entidad Investigador: `get_researcher_detail`
  * Entidad Producción (GNC): `get_article_detail`, `get_book_detail`, `get_book_chapter_detail`
  * Entidad Grupo: `get_group_detail`
* **Motor de Búsqueda Global:** Implementación del endpoint transversal `global_search` en la lógica de vistas para facilitar consultas unificadas sobre cualquier entidad indexada de la Universidad.
* **Exportador en Formato Tabular Avanzado (Capa Excel):** Puesta en marcha de las funcionas `export_group_detail_excel` y `export_researcher_detail_excel` que orquestan OpenPyXL para vaciar métricas estructurales mediante streams directos `.xlsx`.

## ⚙️ Arquitectura de Scraping (Data Mining)

* **Refactorización del Motor de Sincronización:** El comando core `sync_scienti.py` evolucionó su control de flujos de asimilación introduciendo una limpieza escalonada post-scraping de 5 etapas (ej. *Enriquecimiento, Descarte de Huérfanos, Mapeo*).
* **Depuradores de Duplicados Indexados:** Se acoplaron comandos maestros de orden transaccional como `cleanup_article_duplicates.py` y `cleanup_books_chapters_duplicates.py`, que ahora utilizan algoritmos predictivos (e.g. `SequenceMatcher` de `difflib`) para unificar productos homónimos extraídos por error.
* **Comportamiento Híbrido de Tareas:** Se inyectó dinámicamente sobre `settings.py` el fallback `CELERY_TASK_ALWAYS_EAGER = True`. Esto fuerza al encolador asíncrono a ejecutar operaciones críticas temporalmente locales cuando el servidor carece de Broker (Redis) en etapas tempranas.

## 🛡️ Correcciones Críticas y Purga (Bugfixes && Cleanups)

* **Rescate Funcional del Descargador Excel (`500 Server Error`):** Se interceptó y alivianó un fallo destructivo (TypeError) acontecido tras el ajuste arquitectónico de las arrays de los autores. Se reconstruyó la lectura de las llaves en OpenPyXL.
* **Regeneración Total de Encoding Regional:** Reprogramación sobre el buffer para evadir *Mojibakes* en codificación dual (UTF-8 a Latin-1 accidental). Palabras corruptas como `AÃ±o` ahora son servidas limpiamente como "Año".
* **Saneamiento Radical de Archivos Basura:** Gran jornada de borrado transversal. Se eliminaron módulos inyectados desde experimentos anteriores en la raíz y subcarpetas *(`patch_*.py, patch_frontend*.js, inject.py`)* que bloqueaban una estampa limpia en Git y en Docker.
